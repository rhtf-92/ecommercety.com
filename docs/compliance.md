# Cumplimiento — Amazon Associates EE. UU.

Reglas no negociables del proyecto (del plan profesional):

1. Aviso de afiliación visible en el sitio ("As an Amazon Associate, T&F
   Picks earns from qualifying purchases") — componente
   `src/components/AffiliateDisclosure.tsx`.
2. Enlaces de afiliado con `rel="sponsored nofollow"`.
3. **Precios y ofertas solo desde la API oficial de Amazon**, siempre con
   fecha/hora; prohibido escribir precios a mano o copiarlos de la página.
4. Imágenes de producto solo vía SiteStripe o la API oficial.
5. **Prohibido el scraping masivo** de Amazon; la licencia no lo autoriza.
6. Sin ocultamiento de enlaces (cloaking): la medición se hace con Tracking
   IDs por canal + eventos de clic propios.
7. Descripciones propias; nunca copiar descripciones ni reseñas de Amazon.
8. El sitio debe estar declarado en Associates Central (ecommercety.com).
9. Nada de usar "Amazon" en la marca, el dominio o el logo.
10. Plazo de la cuenta: **3 ventas calificadas antes del 29 de abril de 2027**.
